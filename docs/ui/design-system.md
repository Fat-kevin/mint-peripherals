# 薄荷外设界面设计

## 产品结构

固定窗口内左侧 184 DIP 为设备导航，右侧随任务改变布局。总览展示产品外形、连接状态和实际电量。设置独立于设备导航，位于底部。品牌只出现一次。

| 方向 | 取舍 |
|---|---|
| 设备架 | 状态一眼可扫，同时平铺全部配置会挤压按键操作。 |
| 任务流 | 调校、映射和诊断容易跨设备查找，需要频繁重新确认当前设备。 |
| 实体工作区 | 从硬件外形进入配置，实体按键与操作区对应，适合在固定窗口里保留一个视觉焦点。采用此方向。 |

G HUB 的设备入口、Synapse 和 Stream Deck 的实体键绑定方式、SteelSeries 的板载能力提示，以及 Final Cut Pro 对象与检查器的关系分别用于验证导航、按键编辑和写入反馈。现有设备图片用来识别具体型号，设备能力来自实际服务。参考 [G HUB](https://www.logitechg.com/en-ph/software/guides/g-hub-basics)、[Synapse](https://mysupport.razer.com/app/answers/detail/a_id/1737)、[SteelSeries GG](https://steelseries.com/gg/engine)、[Stream Deck](https://docs.elgato.com/streamdeck/sdk/guides/actions/) 和 [Final Cut Pro](https://support.apple.com/en-ca/guide/final-cut-pro/ver2a27194eb/mac)。

## 页面

- **总览**。三个设备共享陈列背景，设备名称、状态和入口与各自实物对齐。未读取的电量显示破折号。
- **耳机**。左侧放置耳机、充电盒和分量读数。右侧可直接选择六种降噪模式和七种 EQ，快捷开关位于其下。查找保留可取消倒计时。模式组使用单独的原生 RadioButton 和应用模板，支持键盘与选中状态。
- **鼠标**。持续显示鼠标实物和设备读数。右侧切换灵敏度、按键、板载与设备，底部保留刷新与写入。分区切换保留同一份待写入配置。设备未返回按键时显示原因。
- **遥控器**。默认展示 RC003 实体按键位置和右侧检查器。实体键选中态持续显示，点手势打开对应动作编辑。全部映射保留批量浏览和接收计数。语音与增益单独成区。
- **设置**。左列切换六个设置分区，右侧仅显示当前分区。备份导入及恢复沿用原有确认和校验方式。

## 视觉与控件

- 深色画布使用矿物灰绿 #161C1B，深色强调色为 #A2D5B9。浅色画布为 #F0F2EC，强调色为 #22664D。主题、桌面静态染色和 Windows 高对比度测试应随主题变更一起检查。
- 横向页面内边距约 32 DIP，主标题 30 DIP，核心标签 14 至 16 DIP，设备状态与辅助内容约 13 DIP。导航高度 46 DIP，模式按钮高度至少 44 DIP。
- 设备陈列与设置检查器使用单层实体表面。模式切换用明显的可点击区域和选中态。长列表与复杂选项在需要时使用原生下拉，连接和失败原因用文本表达。
- 验收优先检查产品图是否属于实际设备、焦点是否落在当前任务、主操作是否像可操作控件、断开时是否给出原因、键盘导航是否能操作。配置界面只显示设备与服务真实支持的能力。

## 原生渲染复核

对比概念稿和 WinUI 实际渲染时，检查了左侧导航与选中态、设备图片和读数的对齐、首屏操作区、标题和辅助文本的字号、深浅主题、操作和错误文案。实物使用项目现有素材，低频的「全部映射」和「板载与设备」保留入口。复核中调整了电量画面、离线文案、遥控器首屏高度和语音空状态。

用离线服务覆盖未连接状态，再用内存设备服务验证交互。内存场景的截图用于复核配置布局，使用测试数据。原生窗口客户区实测为 1264×831，窗口外框仍固定 1280×840。

## 稳定性

- 固定窗口 1280×840、不可缩放/最大化；尺寸只在 `InitializeComponent` 之前设置一次。
- 不使用 `Flyout`、`ContentDialog`、`StartBringIntoView` 做主交互。
- 15 秒刷新只更新文本/数值，不重建 `BitmapImage`、`ItemsSource` 或大控件树。
- 后台事件回 UI 线程必须 `DispatcherQueue.TryEnqueue`。
- 页面 `Unloaded` 退订 `Changed`/`RemoteButtonReceived`、停计时器、恢复 `mappings.suspend=false`。
- 主题切换不重建页面：XAML token 自动更新；代码画笔只重设 Brush，不重建
  `ItemsSource`/`BitmapImage`/控件树。
- 页面加载时用 `PageScroll.ChangeView(null,0,null,true)` 复位到顶部，避免缓存页被焦点带回中部。
