# 薄荷工作台 v4 —— 对齐与密度修复方案

> 2026-10-22 第四轮。用户截图反馈三个硬伤：
> 1. **三列垂直错位**：每列内容自然流布局，名称/说明行数不同 → 圆环不在同一水平线，比例不一；
> 2. **白底方块仍像卡片**：`AppInnerPanelStyle` 的白色矩形（ANC/EQ、连接固件、DPI 档位、图片底板）在雾白画布上仍是一个个"框"；
> 3. **耳机分量实物图丢失**：`yuandao-left.png` / `yuandao-right.png` / `yuandao-case.png` 一直在 Assets，第二轮重设计时被 BatteryRing 替换掉了——图片即设备身份，不能丢。
>
> 网络调研在本环境不可用（DNS 拦截）；本方案基于 WinUI 3 / Windows 11 官方几何规范
> 与 Windows"蓝牙和其他设备"页的既有模式。

## 一、设计规则（本轮硬约束）

### 对齐
- **并列列必须共享同一套 RowDefinitions**，行高全部用固定像素；
  禁止各列各自 `StackPanel` 自然流（这是错位的直接原因）。
- 8px 基线网格；所有行高、间距是 4 的倍数。

### 圆角与几何（对齐 Windows 11 标准）
- 按钮圆角 10 → **8**（Win11 标准）；面板 8；胶囊 999。
- 页标题 30 → **28** SemiBold。

### 表面（"卡片"的最终裁决）
只有两种合法的"块"：
1. **输入控件本身**（ComboBox/TextBox/滑块：白底 1px 细边 8 圆角——这是控件，不是卡片）；
2. **数据表格**（遥控器映射表：白底 1px 边 8 圆角）。
其余一切内容直接放在画布上；**白色矩形面板全部废除**（`AppInnerPanelStyle` 转透明）。

### 图片即身份
设备实物图直接浮在画布上（PNG 自带透明通道），**不加底板、不加描边**；
图片下方紧跟它的电量环。图片丢失 = 身份丢失。

## 二、各页结构

### 设备中心（修复错位的核心）
三列共享固定行网格，逐行对齐：

```
行0  图片   100px   yuandao-case / g304(动态) / rc003，直接浮在画布
行1  电量环  96px    BatteryRing，设备色
行2  名称   24px    15px SemiBold 单行省略
行3  状态   26px    StatusChip
行4  说明   36px    12px 两行，居中
```
- 列间 1px 细分隔线；整列是按钮，悬停薄荷浮起（8 圆角）。
- 行高固定 ⇒ 三列圆环/名称/状态严格同一水平线。

### 耳机（找回图片）
- 页头一行：标题 + 副题 + 查找按钮（主操作在右上）。
- **分量条**（共享行网格 3 列，固定行高）：

```
行0  实物图 72px   yuandao-left / yuandao-right / yuandao-case
行1  电量环 64px
行2  标签   20px   左耳 / 右耳 / 充电盒
行3  状态   18px   充电中 / 使用中 / 已充满
```
- 下方降噪/开关、连接固件：去白底块，区块标题 + 细分隔线，输入控件直接放。

### 鼠标
- 页头：实物图浮空 + 标题/设备选择 + 电量环；读数条固定行高。
- DPI 档位：去掉五个白底块，TextBox 直接排（输入控件自带白底）。

### 遥控器
- 页头同构（rc003 浮空 + 环 + 连接/断开）；扫描行在细分隔线下。
- 产品图面板去白底。

### 设置
- 已经是行 + 细分隔线，保持。

## 三、落地顺序

1. `Tokens.Type.xaml`：页标题 28；`Controls.xaml`：按钮圆角 8。
2. `Cards.xaml`：`AppInnerPanelStyle` → 透明无边（仅映射表代码自带白底，不受影响）。
3. 设备中心：共享行网格重写三列。
4. 耳机：页头 + 分量图条重写。
5. 鼠标/遥控器：图片底板与档位白块移除。
6. 一次构建、一次启动、UIA 全页验证 + 截图。
