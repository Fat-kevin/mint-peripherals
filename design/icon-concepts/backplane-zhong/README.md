## 概念

- 小尺寸读作 **「中」**：外框 + 贯穿竖脊，两个负空间；16px 仍清晰。
- 大尺寸读作 **设备背板/总线**：外框 = 机箱，竖脊 = 共享总线，左右开口 = 设备通道，竖脊两端 = 连接端子。
- 不是三个设备节点的星形图，不是蓝牙符文、齿轮或网络共享图标。
- 无渐变、无发光、无阴影；小尺寸单独手绘，不从 256 缩图。

## 色彩

| 元素 | 值 |
|---|---|
| 底板（常规） | `#0F6673` |
| 底板（16/24，提亮） | `#14717F` |
| 图形 | `#F6F3EA` |
| 32+ 内圈 | 白 15% 叠加（约 `#357D88`） |
| 48+ 可选激活端子 | `#8FA6FF` |

对比度：图形/底板 5.97:1；底板/浅色任务栏 5.97:1；深色任务栏 2.46:1（所以 32+ 加内圈，16/24 用更亮底板）。

## 导出

- ICO 9 帧：16, 20, 24, 32, 40, 48, 64, 128, 256；16/20/24 手绘，40 由 48 派生，256 用 PNG。
- PNG：256 营销图；16/24/32 生产图（标题栏用 16）。
- 标题栏：16px PNG（当前实现）；不再把 32px 缩到 16 DIP，也不硬编码图标字体。
- 托盘：按 `GetDpiForSystem()` + `GetSystemMetricsForDpi(SM_CXSMICON, dpi)` 选帧，不硬编码 16。
- 生产同步点：EXE、`AppWindow.SetIcon`、标题栏、托盘、安装器快捷方式、Windows 图标缓存。

## 风险

「中」在通知区域可能被误读为中文输入法。保留深青底板、`szTip="外设中枢"`；若仍有歧义，OS 图标改用无字的“三通道背板”，中字形只作为应用内品牌。

## 来源

概念与实测来自本项目的 icon audit；预览由离线脚本渲染，未引入第三方图标包。Fluent UI System Icons（MIT）只作为未来 16px `PathIcon` 几何来源，不打包其 TTF。
